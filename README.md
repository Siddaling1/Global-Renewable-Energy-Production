# 🌍 Global Renewable Energy Production & Consumption Analysis

## 🔹 Overview
This project explores global renewable energy data from **2015–2024**, focusing on **production, consumption, CO₂ emissions, efficiency**, and **economic factors** across multiple countries and continents.  
It integrates **Python**, **MySQL**, and **Power BI** to deliver a complete data analytics workflow — from cleaning to visualization.

## 🧠 Objectives
- Identify top renewable energy–producing countries and continents.  
- Compare **energy production vs consumption** to find self-sufficient nations.  
- Analyze **CO₂ emission patterns** and **efficiency rates**.  
- Examine the correlation between **GDP per capita** and **energy output**.  
- Build an **interactive Power BI dashboard** to visualize key insights.
